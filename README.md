# Writeups

Hands-on security labs, each documented with method, evidence, limitations and a short **GRC section mapping the findings to ISO/IEC 27001:2022**.

The goal is not just *"it worked"* but *"what does this mean for risk, and what would I recommend?"*

| Section | Content |
|---|---|
| [🛡️ Defensive](defensive/README.md) | Detection engineering, monitoring, forensics, hardening |
| [⚔️ Offensive](offensive/README.md) | Machines, labs and CTF challenges |

---

*All work is done in isolated lab environments on systems I own or am explicitly permitted to test.*
